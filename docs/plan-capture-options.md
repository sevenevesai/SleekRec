# Plan: capture options for the next release

Goal: ship the four features in
[spec-encoder-compression-mkv-hotkey.md](spec-encoder-compression-mkv-hotkey.md), each verified
on the development machine (RTX 2080 Ti, NVENC), then bump and release when the owner is
satisfied. No version bump, tag, push or release is part of this plan.

The orchestrator owns this file and ticks items as they land on local `main`. Workers read their
spec section and do not edit this file.

## Wave 0: shared contract (orchestrator)

- [x] Settings types, defaults and validation for all four features: `encoderPreference`,
  `mp4MaxGB`, `afterRecording`, `compression`, `fitTargetMB`, `recycleMasterAfterCompress`;
  `SavedRecording.note`; `normalizeCompression`.

## Wave 1: three parallel workers

- [x] SAVE (spec section 3): MKV above `mp4MaxGB` for a single part, MP4 without faststart above
  4 GiB, the note, the overlay hint, measured finalize throughput (figures in `recording.md`).
- [x] ENCODER (spec section 1, phase 1): probe every family, `encoderPreference` at start and
  for exports, x264 export choice, Settings and card text.
- [x] COMPRESS (spec section 2): `compress` export mode, custom fit size, automatic job after a
  recording with the wait-and-requeue rule, opt-in master recycle.

Merge order: SAVE, ENCODER, COMPRESS. Each is rebased onto the previous before its gates rerun.
All three add a block to `src/SettingsModal.tsx`; each keeps to its own block.

## Wave 2

- [x] HOTKEY (spec section 4): first-use fallback to the display under the cursor; the smoke
  test sends the first press to the real app.
- [x] Integration: `npm run test:recording` prints `SMOKE PASS` on merged main, including the
  automatic copy yielding to a recording. The smoke test now waits for a source card and shows a
  corner counter, since an idle desktop starved the browser-engine step.

## Left to the owner

- Not seen on screen by anyone: the "will save as MKV" overlay hint and the MKV note on the cards
  (they need a single-part recording over 8 GB), and the Recycle Bin opt-in with a real file (unit
  tests inject the trash call). Try both once before release.
- Hotkey matrix in real games (borderless, exclusive fullscreen, elevated, anti-cheat); results
  go into `hotkeys-and-tray.md`.
- AMF and Quick Sync runs on AMD and Intel hardware (`roadmap.md` item 2). The encoder
  preference exposes those families only when their probe passes, and the UI does not call them
  tested.
- Version bump and release.

## Pickup notes

Gates for every slice: `npx tsc --noEmit` clean, `npm test` all passing with the total rising,
`npm run test:recording` printing `SMOKE PASS` for anything touching capture or stop. The remote
is public: nothing is pushed.
